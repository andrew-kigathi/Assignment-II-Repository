Domain Name Server (DNS)

Home page

Definition: A Domain Name Server (DNS) is a system that translates human-readable domain names (like www.example.com) into IP addresses (like 192.168.1.1). This allows users to access websites using easy-to-remember names instead of numerical IP addresses.

How it works: When a user types a domain name into their web browser, the browser sends a request to a DNS server to resolve the domain name into an IP address. The DNS server looks up the domain name in its database and returns the corresponding IP address to the browser, which then uses that IP address to connect to the web server hosting the website.
Examples: Some popular DNS servers include Google Public DNS (8.8.8.8 and 8.8.4.4), Cloudflare DNS (1.1.1.1 and 1.0.0.1), and OpenDNS (208.67.222.222 and 208.67.220.220).
