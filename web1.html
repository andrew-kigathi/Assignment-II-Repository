Web 1.0

Home page

Definition: Web 1.0 refers to the early stage of the World Wide Web, which was primarily focused on static web pages and limited user interaction. It was characterized by a read-only web, where users could only consume content without the ability to contribute or interact with it.

Features: Web 1.0 was marked by static HTML pages, limited multimedia content, and a lack of interactivity. Websites were primarily informational, and users had minimal opportunities for engagement or collaboration. The web was primarily used for browsing and consuming information, with little emphasis on user-generated content or social interaction.
Examples: Some examples of Web 1.0 websites include early versions of Yahoo!, AOL, and GeoCities. These websites were primarily focused on providing information and services, with limited user interaction or content creation capabilities. Web 1.0 laid the foundation for the evolution of the web, leading to the development of Web 2.0 and beyond, which introduced more dynamic and interactive web experiences.
