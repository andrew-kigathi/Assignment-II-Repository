Uniform Resource Locator (URL)

Home page

Definition: A Uniform Resource Locator (URL) is a reference (an address) to a resource on the internet. It specifies the location of a resource and the protocol used to access it.

How it works: A URL consists of several components, including the protocol (e.g., http, https), the domain name (e.g., www.example.com), and the path to the specific resource (e.g., /page1). When a user enters a URL into their web browser, the browser uses the protocol to communicate with the server at the specified domain name and retrieves the requested resource.
Examples: Some examples of URLs include:
  • https://www.google.com
  • http://www.example.com/page1
  • https://www.wikipedia.org/wiki/Uniform_Resource_Locator
